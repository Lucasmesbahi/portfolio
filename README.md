# Salaheddine Mesbahi — Portfolio

Static multi-page site (HTML, CSS, vanilla JS). No build step.

## Run locally
- Open `index.html` in a browser, or run `python3 -m http.server 8000` in this folder and visit http://localhost:8000
- Google Fonts need an internet connection; fallbacks are defined.

## Structure
index.html, about.html, skills.html, projects.html, journey.html, contact.html, css/style.css, js/main.js, img/profile.jpg
